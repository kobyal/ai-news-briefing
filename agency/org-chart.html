How you run it

Three ways to interact · the rhythm · what comes back to you

🚪

The Front Door

/cos

Not sure who owns it? Hand any request to the Chief of Staff — it routes to the right team, or gives you the unified "where are we?" digest. When in doubt, start here.

🏛️

The Room

/strategy · /standup · /retro

Run a whole department meeting. The agents debate, do the work, and hand back a board/backlog + a short digest with a ⚠️ action list.

👤

The 1:1

"Maya, dig into…"

Talk to one specialist for depth. Just address them by name with a focused task. No ritual needed.

Daily~2 min
  • Skim BOARD.md + ops/backlog.md
  • Act on any ⚠️ Needs-Koby line
  • Ignore everything that's handled
Weekly~15 min
  • /strategy → fresh bets
  • /standup → health + PRs
  • /retro → make it smarter
As needed—
  • /cos to triage anything
  • /investigate a nasty bug
  • A 1:1 when you want depth

📥 What comes back to you

Every board, backlog, and digest ends with a ⚠️ Needs Koby section — your whole action list. Usually a short set of:

  • merge this PR
  • run this deploy command
  • approve this post / spend
  • make this strategic call

Everything else is already handled — you don't have to read it.

🔒 The safety gate

Agents are mechanically blocked from anything irreversible: git push, git merge, aws s3 sync, CloudFront invalidation, commit on main.

When you want to do these yourself, launch with the gate off:

  • AGENCY_UNLOCK=1 claude
