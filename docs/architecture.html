③ Publish — data preparation
🔧

publish_data.py

Combines all agent outputs → docs/data/DATE.json. Adds Reddit, Twitter, YouTube, GitHub directly. Generates 4 MP3s per story (EN+HE × summary+detail).

🔎

build_search_index.py

Walks every docs/data/*.json → static search-index.json with 7 resource types. No Lambda needed for search.

HF models, HF Spaces, Docker Hub, PyPI, npm → hot_tools.json with GitHub org avatars + Hebrew descriptions.

Operational Safeguards
Three-Layer URL Defense

Merger prompt forbids invented URLs → pipeline drops URLs not in source → publish_data.py keyword-matches page titles. Prevents cross-story URL misassignment.

Branch Guard

local-cycle.sh auto-switches to main if on a feature branch. Prevents Monday-data-loss incident (2026-05-18).

Duplicate Email Guard

email_status.json records sent_at + recipient. If email already sent today, cycle.sh skips re-run entirely.

5-Hour CI Skip Window

Marker file .via_subscription.done signals GitHub Actions to short-circuit within 5h of local subscription run. No double-billing.

EN/HE Parity Audit

publish_data.py flags mismatched story counts between briefing.stories and briefing_he. Surfaced in daily email.

Fallback Tracker

Every API key rotation logged to _fallbacks.jsonl. Uploaded to S3. Surfaced in daily email so silent degradations never hide.

Git Email Lock

Global pre-commit hook rejects commits with bank email (@bankleumi.co.il). Always uses kobyal@gmail.com. Hard-wired to prevent SOC recurrence.

QA Evaluator (nightly)

LangGraph 6-node check: data integrity, URL health, images, sections, content quality, live Playwright probes with functional tests.
